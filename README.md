# Spendly

**Language:** Swift · **Framework:** SwiftUI · **Development Environment:** Xcode

Spendly is an iOS personal-finance application developed for Cooper Union STEM Saturday. It was created to help users record daily income and expenses, organize their financial activity, and understand their spending habits without the complexity often found in larger budgeting platforms. The central goal of the project is to make personal-finance tracking simple, clear, and approachable.

When the app opens, users are guided through a login and sign-up system. An optional App Lock adds another layer of protection before financial information can be accessed. After unlocking the app, the home screen presents the current monthly balance, total income, total spending, and recent transactions in a compact card-based layout. This gives users an immediate overview of their financial situation instead of requiring them to search through several screens.

Users can create separate ledgers for different purposes, such as daily expenses, travel, or a monthly budget. Each ledger can be named and assigned an icon so that different groups of transactions are easy to recognize. Transactions can also be viewed by date, allowing users to review how their spending changes across specific days or time periods.

The central plus button opens the transaction-entry screen, where users can record an event, amount, category, payment method, and optional note. Once transactions are entered, Spendly automatically organizes the data and presents charts and summaries on the analytics screen. These visualizations are intended to make patterns easier to recognize and help users develop greater financial awareness.

The profile area brings together account and application controls, including personal information, security, feedback, settings, and general app information. Users can update their profile details, adjust the appearance of the app, manage security features, and choose from the available languages. Spendly currently includes localization support for English, Chinese, Japanese, Korean, French, and Spanish.

The interface was designed around simplicity. Purple was selected as the main theme color because it suggests creativity and modern design while maintaining a calm visual tone. Rounded cards and controls make the interface feel softer and more approachable. Rather than adding unnecessary features, the design prioritizes the essential tasks of recording, reviewing, and understanding financial activity so that users can complete common actions quickly.

Spendly was developed in Xcode with Swift and SwiftUI. The project uses reusable views, observable data stores, local persistence, CryptoKit password hashing, transaction models, analytics logic, localization management, camera and photo-library integration, and responsive light and dark appearance settings. The repository includes the complete application source code, asset catalog, privacy configuration, and Xcode project.

The current version supports account creation and sign-in, secure local authentication, App Lock, multiple ledgers, income and expense entry, date-based transaction review, financial summaries, charts, profile customization, appearance controls, and multilingual text. Future development could include monthly budget planning, more detailed spending insights, improved translations, cloud synchronization, and a dedicated support page with instructions and frequently asked questions.

By presenting financial information clearly and keeping the workflow easy to understand, Spendly aims to help users become more aware of where their money goes and make more informed everyday decisions. Overall, the project explores how thoughtful interface design and accessible data visualization can make personal-finance management less intimidating.

AI tools were used to assist with coding, debugging, and documentation. The project concept, visual direction, feature planning, interface decisions, testing, and final implementation were completed and reviewed by the project creator.
