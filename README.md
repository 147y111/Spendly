# Spendly

Spendly is an iOS personal-finance application developed for Cooper Union STEM Saturday. The app helps users record income and expenses, organize multiple ledgers, review financial summaries, and better understand their spending habits through a clear SwiftUI interface.

The project includes account creation and sign-in, ledger management, transaction entry, analytics, profile customization, app-lock security, appearance settings, and multilingual support. It was developed in Xcode using Swift, SwiftUI, CryptoKit, local data persistence, and Apple interface frameworks.

The current version contains the complete application source code and Xcode project. A demonstration video and additional visual documentation will be added later.

AI tools were used to assist with coding, debugging, and documentation. The project concept, interface decisions, feature planning, testing, and final implementation were completed and reviewed by the project creator.
